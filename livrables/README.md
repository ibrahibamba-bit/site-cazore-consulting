# Livrables

Ce dossier contient tous les outputs produits par Karl pour Ibrahima.

---

## Règle d'or

| Quoi | Où |
|------|----|
| **Inputs** (documents fournis par Ibrahima : PDFs, exports, notes, briefs) | `context/import/` |
| **Outputs** (tout ce que Karl produit : sites, scripts, contenus, outils) | `livrables/` |

---

## Organisation

```
livrables/
├── sites-web/       Sites internet, landing pages, pages de vente
├── applications/    Outils, scripts, automatisations, bots
├── youtube/         Briefs vidéos, scripts, hooks, calendrier éditorial
├── cabinet/         Livrables pour le cabinet Cazore Consulting
└── ecole/           Livrables pour Apreneur Académie
```

---

## Convention de nommage des projets

Format : `AAAA-MM_nom-court-du-projet`

Exemples :
- `2026-05_landing-agence-immo`
- `2026-06_script-youtube-automatisation-rge`
- `2026-05_offre-sprint-sourcing`

Chaque projet est un sous-dossier dans la thématique correspondante.
Si un projet touche plusieurs thématiques, place-le dans la plus pertinente et note les autres dans son README interne.
